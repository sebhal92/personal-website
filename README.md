- Networking & Enterprise Infrastructure

---

## 🧩 Tech Stack

The website is built using:

- **Jekyll** (GitHub Pages)
- **TailwindCSS** (via CDN)
- **HTML includes** for modular structure
- **Schema.org Person** for SEO
- **Custom SVG favicon**
- **Two‑language support (EN/PL)** via lightweight JS translations
